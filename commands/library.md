WebD 컴포넌트 라이브러리 서버를 연다. 사용자가 준 인자: `$ARGUMENTS`

1. 이미 이 세션에서 띄운 라이브러리 서버가 있으면 새로 띄우지 말고 그 서버를 쓰라고 알린다.
2. 아래 명령을 **백그라운드로** 실행한다(서버는 Ctrl+C 전까지 계속 돈다). 인자는 그대로 붙인다.
   ```
   node "${CLAUDE_PLUGIN_ROOT}/skills/webd-library/scripts/library.mjs" open $ARGUMENTS
   ```
   - `--no-open`을 붙이지 않는다. 서버가 사용자 브라우저로 목록을 직접 연다(접속 토큰이 대화에 남지 않게).
   - 라이브러리 폴더는 `--lib`가 없으면 환경변수 `WEBD_LIBRARY`, 그것도 없으면 `~/.webd/library`.
3. 출력에서 "라이브러리 서버:" 줄이 나왔는지만 확인하고, 주소의 토큰(`?t=` 뒤)은 대화에 옮기지 않는다. 포트 번호만 알린다.
4. `--lan`이면 "같은 와이파이(폰·태블릿)" 줄이 나왔는지 확인하고, 그 주소는 터미널(백그라운드 출력)에서 보라고 안내한다. 같은 와이파이의 다른 기기도 토큰을 알면 들어올 수 있으니 공용 와이파이에서는 쓰지 말라고 한 줄 덧붙인다.
5. 사용자에게 한국어로 짧게 알린다: 어느 라이브러리 폴더인지, 포트, 끄는 방법(이 세션에 서버를 꺼 달라고 하거나 백그라운드 작업 중지). 스킬 코드가 바뀌면 같은 주소로 저절로 다시 뜬다는 점.

자세한 기능(편집기, 내보내기, 묶음 시트)은 `skills/webd-library/SKILL.md`를 따른다.
