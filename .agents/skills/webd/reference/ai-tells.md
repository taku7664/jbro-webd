# AI 티 목록

모델이 아무 결정도 하지 않았을 때 나오는 패턴입니다. 대부분은 **금지가 아니라 기본값**입니다. 사용자가 원했거나 브리프가 이유를 주면 써도 됩니다. 사용자가 비워 둔 축에서 이 중 하나를 쓰고 있다면, 결정을 안 했다는 신호이므로 그 요소를 다시 정합니다.

**[금지]** 표시는 브리프가 원하지 않는 한 쓰지 않습니다.

## 페이지 뼈대

- 아이콘 + 제목 + 짧은 설명 카드를 같은 크기로 3–6개 반복하는 구성
- 큰 숫자 + 작은 라벨 + 보조 지표 + 포인트 색으로 된 히어로
- [금지] 모든 섹션 제목 위에 붙은 작은 대문자 라벨(eyebrow, kicker)
- 히어로 제목 위의 알약 모양 배지("✨ New")
- 내용이 순서가 아닌데 붙이는 01 / 02 / 03 번호
- 모든 걸 가운데 정렬
- 필요 없는 모달

## 표면

- [금지] 그라디언트 텍스트
- 장식으로 쓰는 글래스모피즘(blur 카드, 빛나는 테두리)
- [금지] 둥근 카드에 한쪽만 두꺼운 색 테두리(border-left 강조 바)
- 네오브루탈리즘 세계가 아닌데 쓰는 블러 없는 딱딱한 오프셋 그림자
- 모든 요소에 똑같은 연한 회색 그림자(`rgba(0,0,0,.1)` 류)
- 모든 요소에 같은 모서리 반경, 또는 과한 반경
- 장식용 그리드·도트 배경, 방사형 빛 번짐 배경
- 의미 없는 스파크라인·진행 링
- 표 칸·입력 묶음·버튼·칩을 전부 1px 테두리 상자로 감싸기 (여백으로 묶을 수 있는 곳의 선)
- 주제의 서식·장부·계기판을 화면 구조로 그린 의상 (도구 화면)

## 색

- 보라–남색–바이올렛 계열 포인트(`#6366F1`, `#8B5CF6`, `#A855F7` 근처)
- 어두운 배경 + 시안/청록 또는 네온 포인트
- 따뜻한 크림 배경(`#F4F1EA` 근처) + 세리프 디스플레이 + 테라코타 포인트(`#D97757` 근처)
- 세리프가 없어도: 크림·종이·상아 바탕 + 황토·적토·테라코타 포인트. 모델이 따뜻한 주제(책, 공방, 가족, 아이)에서 습관적으로 고르는 조합입니다(`visual-quality.md` 7절)
- 회색 화면 + 포인트 하나를 "절제"라고 부르는 것 (도구 화면의 기본값. 틀에 색을 쓰지 않음)
- 거의 검정 배경 + 형광 초록 또는 주홍 포인트 하나
- 색 배경 위의 회색 텍스트
- 수정하지 않은 Tailwind/shadcn 기본 토큰

## 타이포

- Inter, Roboto, Open Sans, Geist, Space Grotesk, system-ui를 별 이유 없이 주 폰트로 사용 (외부 폰트를 쓸 수 없다는 제약이 있으면 시스템 한글 고딕 스택은 AI 티가 아닙니다. 제약을 `DESIGN.md`에 적고, 개성은 크기·굵기·자간·숫자 표기로 냅니다)
- "기술 느낌"을 내려고 쓰는 모노스페이스 (코드·데이터·측정값이 아닌 곳)
- 제목에서 한 단어만 이탤릭·굵게·다른 색으로 강조
- 라벨을 전부 대문자로
- 이탤릭 세리프 디스플레이 제목
- 위계가 평평함(크기·굵기 차이가 작음)

## 모션

- 모든 섹션에 같은 fade-in-from-below
- 모든 카드에 hover 효과
- bounce·elastic 이징
- 깜빡이는 상태 점, 장식용 커서 깜빡임, 자동으로 흐르는 마키

## 카피

- "세계 최고 수준", "혁신적인", "차원이 다른", "supercharge" 같은 상투어
- "단순한 기능이 아닙니다. 플랫폼입니다." 같은 억지 대비 문장
- 엠대시(—) 남발
- 메타 정보를 가운뎃점으로 이은 문자열("A · B · C")이 모든 곳에 등장
- 링크·버튼 문구 끝에 습관적으로 붙인 `→`
