# 포트폴리오·갤러리·쇼케이스

모드: Experience. 판단 기준: `modes.md` Experience, `styles/museum-label.md`.

## 원칙

- **작품이 첫 화면을 이끕니다.** 자기소개 문단보다 대표 작품 하나가 먼저.
- UI는 물러납니다: 작은 이름, 작은 내비게이션, 작품을 가리는 글자·버튼·덮개 없음.
- 작품 사이 여백이 디자인입니다. 작품마다 배치를 조금씩 바꿔 리듬을 만듭니다.

## 목록

- 작품이 아주 많으면 목록 페이지가 필요합니다. 그때도 같은 크기 썸네일 격자보다, 대표작은 크게·나머지는 작게, 또는 연도·분야로 묶은 목록.
- 필터·정렬·태그를 한꺼번에 첫 화면에 늘어놓지 않습니다. 한 화면에서 할 결정은 "어느 작품을 열까" 하나.

## 작품 상세

- 작품 이미지·영상 크게, 확대 보기는 사용자가 누를 때.
- 캡션: 제목, 역할, 연도, 재료·도구, 의뢰처. 실제 정보만.
- 과정(스케치, 버전)은 작품을 본 뒤에.
- 이전·다음 작품으로 바로.

## 이미지

- `aspect-ratio`로 자리 확보, `srcset`으로 적절한 해상도, 첫 작품만 우선 로딩·나머지 지연 로딩.
- 대체 텍스트는 작품 내용을 설명(캡션 반복 금지).
- 이미지 위에 글자를 올리지 않습니다. 올려야 하면 대비를 그 위에서 계산(`craft-floor.md`).

## 연락

- 한 곳에 분명히(이메일 복사 버튼, 연락 양식은 짧게).
- 이력서 PDF는 크기·형식 표시.

- 작품을 가리는 요소가 없는가?

- 키보드로 작품 사이를 이동하고 확대 보기를 닫을 수 있는가?
