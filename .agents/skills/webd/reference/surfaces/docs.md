# 문서·가이드·블로그

모드: Read. 판단 기준: `modes.md` Read, `foundations/typography.md`, `foundations/hangul.md`.

## 첫 화면

- 내비게이션과 **지금 위치**(사이드 트리의 현재 항목, 브레드크럼)
- 제목, 그리고 독자의 질문에 바로 답하거나 틀을 잡는 첫 문단
- 본문 칼럼
- 앞으로 가는 길: 이 페이지 목차(넓은 화면 오른쪽), 섹션 제목, 이전·다음

## 본문 칼럼

- 읽기 서체, 본문 16–19px, 한글 행간 1.7 안팎, 한 줄 35–45자(라틴 60–75자).
- 제목 단계 건너뛰지 않기, 섹션 제목에 앵커 링크(복사 가능).
- 본문 뒤에 장식 없음. 세계(색·서체·시그니처)는 틀(머리, 레일, 섹션 시작, 코드·표 처리)에서.

## 코드

- 고정폭 서체(한글 주석이 있으면 한글 포함 고정폭 또는 대체 폰트 지정).
- 복사 버튼, 언어 표시, 긴 줄은 가로 스크롤(줄바꿈하면 코드 의미가 바뀔 수 있음).
- 구문 강조 색도 대비 기준을 지킵니다.
- 명령어와 출력을 구별.

## 참고 자료 형태

- 매개변수 표: 이름(고정폭), 형식, 필수 여부, 기본값, 설명.
- 주의·경고·팁 상자: 종류마다 아이콘 + 글자 라벨(색만으로 구별하지 않음). 한쪽만 두꺼운 색 테두리는 AI 티이니 다른 처리로.
- 다이어그램은 SVG + 글 설명.

## 검색

- 어디서나 같은 위치, 단축키(`/` 또는 Ctrl+K).
- 결과에 페이지 제목 + 섹션 + 일치한 문장.

## 블로그·긴 글

- 제목, 작성자, 날짜, 읽는 시간(선택).
- 각주·주석은 여백에(넓은 화면) 또는 본문 아래(좁은 화면)(`styles/field-notes.md`).
- 이미지는 본문 칼럼보다 넓게 나갈 수 있음(넓은 화면).
- 관련 글은 글 끝에 한 묶음. 본문 중간에 흩뿌리지 않기.

## 변경 내역

- 날짜·버전으로 묶고, 변경 종류(추가/변경/수정/제거) 라벨.
- 사용자가 해야 할 일(마이그레이션)이 있으면 맨 위로.

## 확인

- 독자가 지금 어디 있고 다음에 어디로 갈지 아는가?
- 본문 한 줄 길이가 기준 안인가?
- 이름을 가리면 다른 제품의 문서라 해도 믿을 만한가? 그렇다면 틀이 세계를 충분히 가져오지 않은 것.
- 인쇄(`@media print`)했을 때 읽히는가?
