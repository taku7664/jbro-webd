# 게임 UI 화면

모드: Play(`modes.md`). 스타일 선택: `taste/game.md`에서 레퍼런스 계열 하나를 고릅니다. 프로젝트 색은 별도로 정합니다. 결과물은 HTML/CSS 시안이며, 게임 엔진으로 옮길 때 구조와 토큰을 그대로 가져갈 수 있게 만듭니다.

## 모든 게임 화면의 공통

- **화면 비율**: 16:9 기준(1920×1080 설계, 1280×720·2560×1440에서 확인). 안전 영역 가장자리 5% 안쪽에 글자·버튼. 크기는 `vw`·`vh` 또는 `clamp()`로 비율에 묶어, 해상도가 바뀌어도 배치가 같게.
- **입력**: 패드·키보드로 모든 것을 할 수 있어야 합니다. 방향키로 포커스 이동, 확인(`Enter`/A), 뒤로(`Esc`/B), 탭 전환(`Q`·`E` 또는 LB·RB). 마우스를 올리면 그 항목이 선택됩니다. 시안에서도 실제로 키 입력으로 움직이게 만듭니다.
- **선택 표시가 가장 강함**: 선택된 항목은 강한 명도 차의 띠·강조 테두리·살짝 커짐 중 둘 이상. 선택이 바뀌는 순간 짧은 이동(120–180ms).
- **버튼 안내 줄**: 화면 아래 오른쪽에 현재 할 수 있는 행동과 키(`[A] 장착  [Y] 버리기  [B] 나가기`). 위쪽 탭 양옆에 `LB`·`RB`.
- **장면 위에 띄우기**: 바탕은 게임 장면(시안에서는 어둡게 깐 그라디언트·흐린 이미지 자리)이고 패널은 반투명 그늘(`--scrim`) 위에. 글자 대비는 그늘 기준으로 보장.
- **숫자**: 표 숫자, 오른쪽 정렬. 수치 변화는 비교로(`+10` 초록, `-3` 빨강) 장비 비교 시 바로 옆에.
- **소리·진동은 시안 밖**이지만, 어떤 행동에 피드백이 있는지 `DESIGN.md`에 적어 둡니다.

## 화면별

### 메인 메뉴
- 큰 게임 제목 또는 로고, 세로 메뉴 4–6개(이어하기가 맨 위), 배경은 살아 있는 장면.
- 선택된 메뉴만 강조하고 나머지는 흐리게. 버전·계정은 구석에 작게.

### HUD (플레이 중)
- 네 모서리에 배치: 왼쪽 위 체력·상태, 오른쪽 위 미니맵·목표, 왼쪽 아래 장비·탄약, 오른쪽 아래 스킬 쿨다운. 가운데는 비웁니다.
- 숫자보다 게이지, 게이지보다 위치. 위급할 때만 색(빨강)과 움직임.

### 인벤토리·장비
- 왼쪽 격자 슬롯(정사각, 수량 표시), 가운데 선택 아이템 상세(이름·등급·수치·설명), 오른쪽 캐릭터 실루엣과 스탯. 또는 실루엣을 가운데 두고 장비 슬롯을 몸 주위에.
- 등급은 색+글자(일반·희귀·영웅…), 장착됨 표시, 무게·칸 수 `15/80`.
- 장착 전 비교: 현재 장비 대비 수치 차이를 상세 옆에.

### 캐릭터·스탯
- 큰 캐릭터 일러스트(자리)와 원형 레벨 게이지 + 큰 레벨 숫자 + 경험치 분수.
- 스탯은 아이콘 + 라벨 + 숫자 두 열. 올릴 수 있는 스탯에는 `+` 버튼.

### 스킬 트리
- 원형 노드 + 1px 연결선, 갈래(직업·속성)마다 영역을 나눔. 잠김·해금 가능·해금됨 세 상태가 형태와 색으로 구분.
- 남은 포인트를 아래 가운데에 크게. 노드에 포커스하면 이름·효과·필요 조건 카드가 옆에.

### 퀘스트·보상
- 목록(진행 중·완료) + 상세(목표 체크, 보상 아이콘). 보상 선택은 카드 2–3장 중 하나, 선택된 카드가 앞으로.

### 상점
- 판매 목록 + 내 재화(오른쪽 위 고정) + 구매 확인. 살 수 없는 항목은 이유(재화 부족·레벨)를 보여 줌.

### 설정
- 왼쪽 분류 탭, 오른쪽 항목. 값은 좌우 키로 바꾸는 선택기(`< 보통 >`)와 슬라이더. 변경은 즉시 미리보기, 되돌리기 가능.

### 대화·자막
- 화면 아래 3분의 1, 화자 이름 + 2–3줄. 선택지는 세로 목록, 선택 강조.

## 상태

빈 인벤토리, 잠긴 기능(조건 표시), 로딩(팁 문구 + 진행), 확인 대화상자(되돌릴 수 없는 행동: 버리기·판매), 오류(저장 실패)까지 만듭니다.

## 검증

- 내부 브라우저에서 1280×720, 1920×1080처럼 16:9로 맞추고 `verify.md` 2절의 페이지 검사를 실행합니다. 선택형 헤드리스에서는 `--widths 1280 --height 720`처럼 폭과 높이를 함께 지정합니다. `bg-uncertain`인 장면·그라디언트 위 글자는 실제 화면에서 확인합니다.
- 조각별로 자동 거르기와 편집기 검토를 거친 뒤 사용자가 확정한 조각만 조립합니다. 조립된 화면도 사용자에게 확인받습니다. `structure.md`의 페이지형 쏠림 점검은 게임 화면에는 해당하지 않습니다.
- 키보드만으로: 탭 전환, 목록 이동, 확인, 뒤로가 되는지 실제로 눌러 봅니다.
- 이름을 가려도 어떤 장르의 게임인지 보이는가, 그리고 선택이 화면에서 가장 먼저 보이는가.
