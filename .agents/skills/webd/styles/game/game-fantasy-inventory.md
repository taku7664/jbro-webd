# 장비 인벤토리 · 판타지

G5에서 아이템을 비교하고 장착하는 Play 화면에 맞습니다.

## 타입

캐릭터 이름과 섹션 제목에 판타지 성격의 제목 서체를 검토합니다. 아이템 정보와 한글은 작은 크기에서도 선명한 서체를 씁니다.

## 색

틀, 슬롯, 포커스, 장착됨, 등급에 별도 역할을 정합니다. 프로젝트에서 색을 정하고 장착 여부와 등급은 문자나 형태로 함께 표시합니다.

## 구성

한쪽에 슬롯 격자, 맞은편에 장비를 입힌 단색 실루엣과 세부 정보. 얇은 장식 모서리는 패널 바깥에 두고 슬롯 안은 읽기 쉽게 비웁니다.

## 컴포넌트

상단 탭 양옆에 LB/RB 또는 Q/E 안내, 하단에 장착·뒤로·버리기 키를 둡니다. 슬롯마다 빈 상태·선택·장착·사용 불가를 표현합니다.

## 모션

이동한 슬롯과 상세 정보가 함께 갱신됩니다. 버리기처럼 되돌리기 어려운 행동은 별도 확인 상태를 둡니다.

## 시그니처

실루엣과 슬롯 격자의 대비, 패널 가장자리에만 남긴 장식 모서리.

## 하지 않는 것

모든 슬롯에 장식과 발광을 얹어 현재 선택 위치를 찾기 어렵게 하기.

## 접근성 주의

패드·키보드로 그리드 이동과 장착·취소를 확인하고, 포커스와 장착 표식이 겹쳐도 둘 다 읽히게 합니다.
