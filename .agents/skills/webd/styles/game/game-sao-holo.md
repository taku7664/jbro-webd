# 단계형 홀로 메뉴 · SAO 풍

G1과 G2의 조작 문법을 사용합니다. 게임 중 메뉴 깊이와 현재 선택을 즉시 알아야 하는 Play 메뉴·HUD에 맞습니다.

## 타입

- 메뉴는 기울임 산세리프와 아이콘을 한 줄에 둡니다. 한글은 기울임으로 판독성이 떨어지면 정자체를 씁니다.
- 체력·레벨·거리 수치는 일정 폭 숫자로, 메뉴 라벨보다 작게 둡니다.

## 색

패널·선택 줄·선택 위 글자·체력·위험 경고를 서로 다른 역할로 정의합니다. 패널은 장면과 분리되는 단색 또는 반투명 면을 선택합니다. 선택 줄은 면 전체의 명도 차로 식별합니다. 실제 색 값은 프로젝트에서 정합니다.

## 구성

원형 아이콘 열을 세로로 두고 선택한 아이콘의 오른쪽에 1단 패널을 엽니다. 2·3단은 각각 이전 패널의 선택 위치에서 오른쪽으로 연결합니다. 작은 삼각형은 열린 경로를 가리킵니다. 패널 외곽은 사선으로 자르고 내부는 라벨과 아이콘의 간격으로 구분합니다.

## 컴포넌트

- 원형 메뉴는 선택된 원과 나머지 원을 면 채움과 형태 변화로 구분합니다.
- 선택 줄은 가로 전체를 채우고 아이콘과 기울임 라벨을 유지합니다.
- 장비 화면은 단색 인체 실루엣 주위에 슬롯 점과 연결선을 둡니다.
- 체력 막대는 기울어진 막대 끝에 셰브런을 두고 아래에 무게·레벨 칩을 붙입니다.
- HUD 모서리에 파티원과 체력선, 거리·온도를 배치합니다. 심박 경고는 파형과 경고 문구를 함께 씁니다.

## 모션

한 단계씩 오른쪽으로 열고 닫습니다. 줄 이동과 패널 열림을 분리합니다. 모션 줄이기 설정에서는 위치와 상태가 즉시 바뀝니다.

## 시그니처

원형 메뉴에서 시작해 삼각 연결부와 사선 패널을 따라 오른쪽으로 이어지는 선택 경로.

## 하지 않는 것

여러 단계의 패널을 처음부터 모두 펼쳐 두기, 상태를 색상 차이만으로 표현하기.

## 접근성 주의

방향키로 같은 층을 이동하고 Enter로 열고 Esc로 한 단계씩 돌아갑니다. 실제 장면 위에서 글자와 선택 표시의 대비를 확인합니다.
