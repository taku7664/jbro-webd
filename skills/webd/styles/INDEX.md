# 스타일 목록

사용자가 스타일 이름을 말하면 이 목록에서 파일을 찾아 **그 파일 하나만** 읽습니다. 다른 스타일 파일은 열지 않습니다. 목록에 없으면 가까운 스타일 2–3개를 제안합니다.

파일 이름 규칙: 스타일 이름을 소문자로, 공백은 `-`로, "스타일"·"style"은 뺍니다. `transit map 스타일` → `transit-map.md`

새 스타일은 `_template.md`를 복사해 만들고 이 목록에 한 줄을 추가합니다.
