# 다이아몬드 스킬 트리 · 어쌔신 크리드식

G3에서 계열별 성장 경로를 탐색하는 Play 화면에 맞습니다.

## 타입

노드 자체는 아이콘 중심으로 두고, 이름·조건·설명은 선택된 노드의 설명 영역에 둡니다. 한글은 좁은 영역에서 읽히는 본문 서체를 고릅니다.

## 색

잠김·해금 가능·해금됨의 역할을 나누고 프로젝트 팔레트를 사용합니다. 선택과 획득은 색 이외에 테두리, 아이콘, 채움에서도 구분합니다.

## 구성

다이아몬드 영역 세 개로 계열을 나누고 원형 노드를 가는 선으로 연결합니다. 계열 이동 탭과 입력 표시는 상단에 둡니다.

## 컴포넌트

잠긴 노드에는 조건, 해금 가능 노드에는 강조 테두리, 해금된 노드에는 채움과 획득 표식을 둡니다. 현재 포커스는 세 상태 모두에서 식별돼야 합니다.

## 모션

포커스 이동과 해금 피드백만 짧게 보여 주고 모션을 줄인 상태에서도 경로가 드러나게 합니다.

## 시그니처

다이아몬드 영역마다 갈래가 퍼지고 연결선이 선행 스킬을 드러냅니다.

## 하지 않는 것

장비 슬롯처럼 모든 노드를 같은 격자에 놓아 연결 관계를 지우기.

## 접근성 주의

방향키와 패드 이동 순서가 연결 관계와 맞는지 확인합니다. 선택 불가 조건을 텍스트로 알립니다.
