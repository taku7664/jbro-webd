# 사용자 기본 취향 · 웹 (JBro)

사용자가 고른 웹 레퍼런스 3장에서 모양·배치·타이포·밀도를 정리했습니다. 브리프에서 비워 둔 스타일 축에 적용합니다. 밝기와 색상은 사용 장면과 프로젝트의 요구로 정하고 필요한 경우 사용자에게 확인합니다.

1. **선 대신 큰 둥근 면**. 패널 반경 20–28px, 면 사이 8–12px. 이웃 면의 명도 차로 영역을 나누고, 테두리는 구분이 필요한 곳에만 씁니다.
2. **알약 컨트롤**. 탭·필터·칩·버튼은 끝을 완전히 둥글게 하고 선택 상태에만 채움을 줍니다.
3. **큰 숫자와 작은 라벨**. 수치는 32–44px, 굵기 400–500과 `tabular-nums`. 단위는 수치의 절반 정도, 라벨은 12px부터 실제 가독성을 확인합니다.
4. **크고 가벼운 제목**. 제목은 36–44px, 굵기 400–500에서 시작합니다. 크기와 여백으로 우선순위를 드러냅니다.
5. **명도 반전 패널 하나**. 주요 작업이나 지표가 있는 면 하나에 주변과 반대되는 명도를 줍니다.
6. **데이터가 장식**. 실제 아바타 묶음, 진행 막대, 작은 곡선 그래프와 타임라인 노드로 밀도와 리듬을 만듭니다.
7. **포인트 색 면적은 작게**. 선택·주 행동·진행처럼 의미 있는 곳에만 써서 해당 상태가 한눈에 보이게 합니다.

한글 본문은 Pretendard를 우선 검토하고, 프로젝트에 지정 서체가 있으면 그 값과 한글 대체 스택을 따릅니다. 패널과 알약의 반경을 의도적으로 선택했다면 `DESIGN.md`에 근거를 적고, 포인트 면 위 글자는 프로젝트에서 고른 색으로 대비를 확인합니다.
