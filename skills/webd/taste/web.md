# 사용자 기본 취향: 웹 (JBro)

사용자가 직접 고른 레퍼런스 3장(2026-11-09)에서 뽑은 **웹 화면의 기본 미감**입니다. 브리프가 시각 방향을 비워 두면 이 문서가 출발점입니다. 프로젝트의 `DESIGN.md`나 이번 요청에서 사용자가 고정한 것이 있으면 그쪽이 이깁니다(`SKILL.md` 우선순위 3). AI 티 목록과 겹쳐도 사용자가 고른 취향이므로 따릅니다(우선순위 4가 5보다 위).

레퍼런스 이미지는 저장하지 않았습니다(제3자 작업물). 측정값과 특징만 남깁니다. 측정: `scripts/image-tokens.mjs`.

| # | 레퍼런스 성격 | 측정한 색 |
|---|---|---|
| W1 | 밝은 회베이지 바탕의 의료 대시보드, 레몬 포인트 | 바탕 `#dfdfd7` (L 0.90), 글자 `#5b5b54`, 포인트 레몬 `#f2fe48`(색상 113°, UI 안에서는 1% 미만) |
| W2 | 무채 회색 와이어프레임, 큰 둥근 면 | `#323232` / `#4a4a4a` / `#666666`, 채도 0 |
| W3 | 짙은 남흑 인보이스 대시보드 + 흰 패널 하나, 라임 포인트 | 짙은 면 `#20242f`·`#0a0b0f`, 흰 패널 `#fdfefd`, 포인트 라임 `#97fd08`(133°, 0.28%) |

## 공통 원칙 (세 장 모두에서 확인)

1. **채도 있는 색은 화면의 1% 안팎.** 세 장 모두 채도 0.06 이상 색 면적이 0–0.5%입니다. 나머지는 무채(밝은 회베이지 또는 짙은 남흑). 포인트는 형광 계열 하나(레몬·라임)를 **현재 선택, 주 행동, 진행 막대**에만.
2. **선 대신 면.** 영역은 큰 둥근 면(반경 20–28px)으로 나누고, 면끼리는 명도 차이(밝은 바탕 위 조금 더 밝은 면, 어두운 바탕 위 조금 더 밝은 면)로 구분합니다. 1px 테두리 상자는 거의 없습니다. 면 사이 간격 8–12px로 타일처럼.
3. **컨트롤은 알약.** 탭, 필터, 칩, 버튼은 완전히 둥근 끝(`border-radius: 999px`). 선택된 알약만 채웁니다: 밝은 화면에서는 흰색이나 짙은 색, 어두운 화면에서는 형광 포인트.
4. **숫자가 주인공.** 금액·지표는 크게(32–44px), 굵기는 400–500으로 가볍게, `tabular-nums`. 단위·통화 기호는 숫자의 절반 크기로. 숫자 바로 위나 아래에 아주 작은 라벨(12px, 흐린 색).
5. **제목은 크고 가볍게.** 화면 제목 36–44px, 굵기 400–500. 위계는 크기 대비로 내고 굵기로 누르지 않습니다.
6. **명도 반전 패널 하나로 초점.** 어두운 화면 안에 흰 패널 하나(W3), 또는 밝은 화면 안에 짙은 알약 하나(W1의 + 버튼). 화면당 하나.
7. **데이터가 장식.** 아바타 묶음, 진행 막대, 작은 곡선 그래프, 타임라인 노드가 화면의 표정입니다. 의미 없는 일러스트·그라디언트는 없습니다.

## 토큰 출발점

```css
/* 밝은 판 (W1 계열) */
--bg: #e1e1d9;        /* 회베이지 바탕 */
--surface: #edede7;   /* 한 단계 밝은 면 */
--surface-2: #f8f8f4; /* 떠 있는 면 */
--ink: #1f201c;       /* 본문·제목 */
--ink-2: #5b5b54;     /* 보조 글자 (바탕 대비 5.1) */
--accent: #e9f53c;    /* 레몬: 선택·주 행동 면에만, 그 위 글자는 --ink */
--invert: #1f201c;    /* 반전 알약 */

/* 어두운 판 (W3 계열) */
--bg: #0b0c10;
--surface: #1c1f28;
--surface-2: #2a2e39;
--ink: #f4f5f2;
--ink-2: #a3a7b0;
--accent: #9dfa1e;    /* 라임: 선택·주 행동·진행에만, 그 위 글자는 #0b0c10 */
--invert: #fdfefd;    /* 반전 패널 하나 */

--radius-panel: 24px;
--radius-control: 999px;
--gap-panel: 10px;
```

밝은 판과 어두운 판 중 무엇을 쓸지는 `visual-quality.md` 2절대로 쓰는 장면으로 정합니다. 두 판 모두 지원할 때는 같은 역할 이름으로 값만 바꿉니다.

## 서체

- 한글은 **Pretendard**(가변, 동적 부분 집합)를 기본으로 씁니다. 숫자·영문 제목에는 기하학적 산세리프 느낌이 맞습니다. Pretendard 자체의 숫자로 충분하고, 따로 쓰려면 한글 대체 폰트를 바로 뒤에 둡니다(`foundations/hangul.md`).
- 외부 폰트를 못 쓰는 환경에서만 시스템 고딕으로 물러나고, 그 사실을 `DESIGN.md`에 적습니다.

## 하지 않는 것

- 1px 테두리로 모든 입력·카드를 감싸기 (면과 간격으로 묶습니다)
- 4–6px의 각진 모서리를 기본값으로 (패널 20px 이상, 컨트롤은 알약)
- 포인트 색을 버튼 여러 개·아이콘·제목에 흩뿌리기
- 회색 무채 화면에 파랑·보라 같은 흔한 SaaS 포인트
- 기기 틀(태블릿 프레임) 안에 화면을 넣는 것은 레퍼런스의 발표용 연출입니다. 실제 웹 화면에는 넣지 않습니다.

## 검사와의 관계

- 알약 모양과 형광 포인트는 `ai-tells.md`의 "같은 반경", "거의 검정 + 형광 포인트"와 겹칩니다. 이 취향을 쓸 때는 `DESIGN.md`「고정」에 "사용자 기본 취향(taste/web.md)"이라고 적고, 해당 검출기 규칙이 있으면 `--allow`로 뺍니다.
- 형광 포인트 위 글자는 반드시 짙은 색(대비 확인). 형광 위 흰 글자는 대비가 안 나옵니다.
