# 사용자 기본 취향 · 게임 UI (JBro)

게임 레퍼런스 5장은 계열별로 나눕니다. 화면의 조작 방식과 필요한 컴포넌트를 보고 이번 프로젝트에 맞는 계열 하나를 고릅니다. 색은 프로젝트에서 별도로 정합니다.

| 레퍼런스 | 스타일 사양 | 맞는 컴포넌트 |
|---|---|---|
| G1·G2 · SAO 풍 메뉴와 HUD | [단계형 홀로 메뉴](../styles/game/game-sao-holo.md) | 원형 메뉴·단계 패널·선택 줄·장비 도식·체력 막대 |
| G3 · 어쌔신 크리드식 스킬 트리 | [다이아몬드 스킬 트리](../styles/game/game-skill-tree.md) | 원형 노드·연결선·계열 전환 |
| G4 · 방패 용사식 캐릭터 화면 | [캐릭터 도감](../styles/game/game-character-sheet.md) | 인물 일러스트·원형 레벨 게이지·스탯 목록 |
| G5 · 판타지 인벤토리 | [장비 인벤토리](../styles/game/game-fantasy-inventory.md) | 슬롯 격자·장비 실루엣·탭·버튼 안내 |

조작과 화면 검증은 `reference/surfaces/game.md`를 따릅니다. 레퍼런스 원본이 필요하면 다시 받아 저장소 밖 임시 위치에서 시안과 나란히 봅니다.
