# 사용자 기본 취향: 게임 UI (JBro)

사용자가 고른 게임 레퍼런스 5장(2026-11-09)에서 뽑은 **게임 화면의 기본 미감**입니다. 게임 UI(Play 모드, `reference/modes.md`)에서 브리프가 시각 방향을 비워 두면 이 문서가 출발점입니다. 프로젝트 `DESIGN.md`나 이번 요청의 고정이 이깁니다.

레퍼런스 이미지는 저장하지 않았습니다(게임 아트·제3자 작업물). 특징과 측정값만 남깁니다.

| # | 레퍼런스 성격 | 측정한 색 |
|---|---|---|
| G1 | 검정 바탕, 원형 아이콘 세로 열에서 오른쪽으로 단계별 메뉴가 펼쳐짐, 선택 줄은 노랑 띠, 사선으로 깎은 패널, 이탤릭 산세리프, 인체 장비 슬롯도 | 바탕 `#000002`, 패널 `#e3e4df`, 포인트 노랑 `#eacc18`(98°), 체력 연두 `#77b517` |
| G2 | 장면 위에 반투명 짙은 HUD 패널, 파랑 선택 띠, 실루엣 장비 화면, 모서리 HUD 정보, 빨간 심박 경고 패널 | 바탕 `#313230`·`#1c201f`, 포인트 파랑 `#478dd0`(250°), 경고 빨강 `#912e2c` |

## 공통 원칙

1. **포인트는 금색·노랑 하나(때로 파랑).** 다섯 장 중 넷의 포인트가 색상 88–100°의 금·노랑입니다. 채도 있는 색은 화면의 0–3%. 선택 줄, 해금 노드, 레벨 게이지, 장비된 표시에만 씁니다. 상태 경고(빨강)와 체력(연두)은 그 의미일 때만.
2. **바탕은 장면이나 깊은 무채.** 게임 장면·아트 위에 UI를 띄우거나(어둡게·흐리게 깐 장면), 거의 검정·짙은 남색·짙은 갈회색 바탕. 밝은 판은 종이·양피지 질감의 회베이지(G4).
3. **선택이 가장 크게 보입니다.** 선택된 항목은 줄 전체를 포인트 색으로 채우거나(노랑·파랑 띠) 금색 테두리+발광. 패드로 움직이는 게임에서 "지금 어디"가 가장 강한 신호입니다. 웹의 얇은 포커스 링이 아닙니다.
4. **계층 메뉴는 옆으로 펼쳐집니다.** 원형 아이콘 버튼 세로 열 → 오른쪽에 하위 패널 → 그 오른쪽에 다음 단계. 패널 사이를 작은 삼각형·화살표로 잇습니다(G1, G2).
5. **캐릭터가 화면의 중심.** 실루엣이나 일러스트를 가운데에 크게 두고, 장비 슬롯·스탯을 그 주변에 배치합니다(G1, G2, G4, G5). 실루엣은 단색(흰색·금색)으로.
6. **숫자와 게이지.** 레벨·스탯은 아이콘 + 라벨 + 오른쪽 정렬 숫자, 짧은 막대 게이지(가로 4–6px), 원형 게이지 안의 큰 숫자. 경험치는 `59/385`처럼 분수로.
7. **노드와 연결선.** 스킬·업적·진행은 원형 노드 + 1px 연결선. 잠김은 반투명, 해금 가능은 테두리 강조, 해금됨은 금색 채움(G3).
8. **장식은 틀에만.** 모서리 장식, 가는 이중선, 문양 원, 사선 컷은 패널의 틀과 제목에만. 목록·숫자 칸 안에는 넣지 않습니다.
9. **입력 안내가 화면에 있습니다.** 상단 탭 양옆에 `LB`·`RB`(또는 `Q`·`E`), 하단에 버튼 안내 줄(`A 장착`, `B 나가기`, `Y 버리기`). 키보드·패드로 다 할 수 있어야 합니다.

## 토큰 출발점

```css
/* 어두운 판 (G1·G3·G5 계열) */
--bg: #12151a;          /* 장면이 없을 때 바탕. 장면이 있으면 장면 위 그늘 */
--scrim: rgb(8 10 14 / .72);   /* 장면 위 패널 바탕 */
--panel: #1d2128;
--panel-2: #262b33;
--line: rgb(255 255 255 / .14);
--ink: #eceee8;
--ink-2: #a9aea6;
--gold: #e2c46a;        /* 선택·해금·장비됨. 그 위 글자는 #12151a */
--gold-dim: #8f7c45;    /* 장식선·비활성 금색 */
--hp: #7cc23a; --danger: #d0473f; --mana: #4f8fd6;

/* 밝은 판 (G4 계열) */
--bg: #e6e5dc; --panel: #f1f0e9; --ink: #1b2416; --ink-2: #4f5648; --gold: #b8954a;
```

## 서체

- 한글 본문: **Pretendard**. 제목·탭: 넓거나 각진 산세리프(이탤릭 허용, G1), 또는 판타지 세계면 세리프 제목(G5의 "Character's Name"). 한글 제목은 그 성격에 맞는 한글 서체를 함께 고릅니다(`foundations/hangul.md`).
- 숫자는 `tabular-nums`, 레벨·스탯 숫자는 크게.

## 하지 않는 것

- 웹 관리자 화면처럼 폼 칸·표 테두리로 채우기
- 장식을 숫자·목록 안까지 끌고 오기
- 선택 표시를 얇은 포커스 링만으로 (게임에서는 선택이 가장 강해야 함)
- 포인트 색을 여러 개 쓰기 (금색 하나 + 의미 색 몇 개)
- 키보드·패드로 이동할 수 없는 화면

## 검사와의 관계

- 발광(금색 노드), 사선 컷, 장면 위 반투명 패널은 `ai-tells.md`의 장식 규칙과 겹칠 수 있습니다. 게임 취향을 쓸 때는 `DESIGN.md`「고정」에 "사용자 기본 취향(taste/game.md)"이라고 적고 해당 검출기 규칙은 `--allow`로 뺍니다.
- 장면 위 글자는 `render-check`가 배경을 계산하지 못합니다(bg-uncertain). 패널 바탕(`--scrim`)을 깔아 대비를 보장하고, 스크린샷에서 직접 확인합니다.
