# audit — 구현 품질 감사

critique가 "디자인이 좋은가"를 본다면, audit은 "구현이 버티는가"를 봅니다. 다섯 영역을 0–4점으로 매기고 문제를 심각도 순으로 보고합니다. 고치라는 요청이 없으면 코드를 바꾸지 않습니다.

## 실행할 검사

```
node "<스킬 폴더>/scripts/detect.mjs" <소스 폴더> --json
node "<스킬 폴더>/scripts/render-check.mjs" <파일 또는 URL> --widths 320,375,768,1440 --scheme light,dark --json
```

dark를 지원하지 않는 화면이면 light만. 검사 결과는 근거이고 판정은 직접 합니다. 오탐은 오탐이라고 적습니다.

## 다섯 영역

### 1. 접근성

확인: 대비(렌더 기준), reduced-motion 경로가 의미 있는 피드백까지 지우지 않는지, 컨트롤의 이름·역할·상태, 키보드 이동·포커스 표시·포커스 갇힘, 의미 있는 HTML(제목 단계, 랜드마크, `div` 버튼), 대체 텍스트, 폼 라벨·오류.

| 점수 | 기준 |
|---|---|
| 0 | WCAG A 미달, 키보드로 못 씀 |
| 1 | 큰 빈틈 (라벨 대부분 없음, 포커스 표시 없음) |
| 2 | 노력은 있으나 큰 빈틈 |
| 3 | AA 대부분 충족, 작은 빈틈 |
| 4 | AA 충족, 일부 AAA 수준 |

### 2. 성능

확인: 반복문 안의 레이아웃 읽기·쓰기, 레이아웃 속성 애니메이션, 범위 없는 blur·filter, 이미지 최적화(형식, 크기, `loading="lazy"`, `width`/`height`), 폰트 파일 크기(한글 부분 집합, `hangul.md`), 쓰지 않는 의존성, 불필요한 재렌더, `will-change` 남용. 지표는 `ops/optimize.md`.

| 점수 | 기준 |
|---|---|
| 0 | 심각 (레이아웃 스래싱, 최적화 전무) |
| 1 | 큰 문제 (지연 로딩 없음, 비싼 애니메이션) |
| 2 | 부분 |
| 3 | 대체로 최적화 |
| 4 | 빠르고 가벼움 |

### 3. 테마·토큰

확인: 토큰 밖 하드코딩 색·간격, 다크 모드 누락·대비 미달, 잘못된 토큰 사용, 테마 전환 때 안 바뀌는 값. 기준은 `design-systems.md`. 근거는 `node "<스킬 폴더>/scripts/css-inventory.mjs" <소스>`의 토큰 밖 색·격자 밖 간격·글자 크기 종류 수.

| 점수 | 기준 |
|---|---|
| 0 | 전부 하드코딩 |
| 1 | 토큰 거의 없음 |
| 2 | 토큰은 있으나 섞여 씀 |
| 3 | 토큰 사용, 작은 예외 |
| 4 | 완전한 토큰 체계, 테마 전환 정상 |

### 4. 반응형·터치

확인: 고정 폭, 가로 넘침, 터치 대상(WCAG 2.2 AA 최소 24×24px, 권장 44×44px), 커스텀 슬라이더·드래그·가로 스크롤 띠가 터치에서 동작하는지(마우스 이벤트만 있음, `touch-action` 없음, 취소 시 상태가 남음), 글자 확대 시 깨짐, 좁은 폭 대응. 기준은 `responsive.md`.

> 에뮬레이션한 화면 폭은 레이아웃만 증명합니다. 터치 제스처는 실제 터치(또는 합성 터치)로 확인했는지 따로 적습니다.

| 점수 | 기준 |
|---|---|
| 0 | 데스크톱 전용 |
| 1 | 큰 문제 다수 |
| 2 | 모바일에서 되지만 거침 |
| 3 | 반응형, 작은 문제 |
| 4 | 모든 폭·터치에서 매끄러움 |

### 5. 구현 무결성 (가장 먼저 판정)

확인: 반복되는 구현 지름길, `DESIGN.md`에서 벗어난 값, 사실이 아닌 카피·장식용 가짜 데이터, 다른 제품에 그대로 옮겨도 되는 구조, 검출기 지적 중 진짜인 것.

| 점수 | 기준 |
|---|---|
| 0 | 체계 없이 제각각 |
| 1 | 같은 실패 반복 |
| 2 | 확인된 문제 여럿 |
| 3 | 작은 개별 문제 |
| 4 | 일관되고 의도적 |

## 주의

- 자동 검사로 잡히는 접근성 문제는 일부입니다. 키보드만으로 주 작업을 직접 해 보고 결과를 적습니다.
- 점수는 증거로. 확인하지 못한 영역은 점수 대신 `미확인`.
