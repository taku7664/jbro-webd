# 랜딩 페이지

모드: Persuade. 판단 기준: `modes.md` Persuade, `foundations/ux-writing.md`, `foundations/ethics.md`.

## 첫 화면이 할 일

1. **무엇인지** 한 문장으로 (제품 범주 + 누구를 위한 것인지)
2. **왜 원하는지** (사용자가 얻는 변화)
3. **이 제품만 증명할 수 있는 것** 하나 (실제 화면, 실제 결과물, 데모, 숫자)
4. **동작하는 주 행동** (방문자가 하러 온 일이 실제로 되는 형태: 검색, 예약 시간, 장바구니, 체험 시작)

흔한 템플릿 히어로(왼쪽 제목·부제·버튼 두 개, 오른쪽 기기 목업, 아래 로고 띠)는 피합니다. 첫 화면은 **주제 세계에서 가장 특징적인 것**으로 엽니다: 제목일 수도, 이미지·애니메이션·실제 데모·상호작용일 수도 있습니다.

## 방문자의 인식 단계에 맞춰 연다

| 방문자가 아는 것 | 첫 화면이 이끄는 것 |
|---|---|
| 문제도 해결책도 모름 | 이야기·놀라운 사실로 끌어들이기 |
| 문제는 앎 | 문제를 알아봐 주고 공감 |
| 해결책 범주는 앎 | 범주의 이점과 우리만의 차이 |
| 우리 제품을 앎 | 기능, 증거, 반론 처리 |
| 살 준비가 됨 | 제안, 가격, 주 행동 |

광고 유입이면 광고 문구와 첫 화면이 이어져야 합니다.

## 섹션 재료 (순서·개수는 내용에 맞게)

| 섹션 | 하는 일 | 주의 |
|---|---|---|
| 히어로 | 가치 제안 + 주 행동 | 위 4가지 |
| 증거 | 실제 고객사·사용자 수·인용 | 실제 것만. 없으면 섹션을 빼고 지어내지 않음 |
| 문제 | 사용자의 문제를 그 사람 말로 | 겁주기 금지 |
| 해결 | 기능이 아니라 **바뀌는 것** | 아이콘+제목+설명 카드 3개 반복 피하기 |
| 작동 방식 | 과정을 보이게 해서 마찰 줄이기 | 단계가 실제로 순서일 때만 번호 |
| 반론 처리 | 안 사는 이유 상위 2–3개에 답 | FAQ와 겹치지 않게 |
| 후기 | 구체적(결과, 직함, 사용 맥락) | 실제 것만 |
| 가격 | `pricing.md` | 숨긴 비용 금지 |
| FAQ | 남은 질문 | 접기 |
| 마지막 행동 | 주 행동을 더 낮은 문턱으로 반복 | 같은 버튼 문구 |

- 고객이 주인공, 브랜드는 안내자입니다. "우리는 혁신을 이끕니다"보다 "당신의 ___가 ___해집니다".
- **구매 = 원함 − (수고 + 혼란)**. 섹션을 더하기 전에 수고와 혼란을 줄이는 게 먼저입니다.
- 모든 섹션이 같은 박자(제목 → 부제 → 카드 3개)로 반복되면 단조롭습니다. 밀도·속도·크기가 바뀌는 정점 섹션을 하나 둡니다.

## 피할 것

- 같은 크기 아이콘 카드 그리드, 큰 숫자 히어로 지표, 제목 위 작은 라벨, 알약 배지("✨ 새로운"), 모든 섹션의 같은 등장 애니메이션, 그라디언트 글자, 보라 그라디언트 (`ai-tells.md`)
- 상투 문구, 근거 없는 수치, 가짜 긴급
- 주 행동이 둘 이상 같은 무게로 경쟁
- 첫 화면 전체를 채우는 무거운 영상·이미지로 느린 LCP (`ops/optimize.md`)
