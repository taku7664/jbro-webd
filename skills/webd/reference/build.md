# 구현

한 조각에 필요한 구조·동작부터 만든 뒤, 글자·간격·표면·선택 효과를 다듬습니다.

시작 전에 `DESIGN.md`를 읽습니다. 없으면 `direction.md`로 돌아갑니다. (기존 화면을 조금 다듬는 요청은 예외: 현재 코드의 값을 기준으로 삼습니다.)

## 조각 목록부터

웹은 견적 패널·알약 탭·수량 표처럼, 게임은 원형 아이콘 세로 메뉴·단계 펼침 패널·선택 줄·체력 막대처럼 화면을 이루는 단위로 나눕니다. 기본·선택·비활성·빈·오류를 목록에 적고, 해당 조각에서 의미 있는 상태와 전환을 구현합니다. UI 코드를 쓰기 직전에 `craft-floor.md`와 `visual-quality.md`를 확인합니다.

한 번에 조각 하나를 단독 HTML로 만듭니다. 레퍼런스와 시안을 내부 브라우저에 나란히 같은 표시 크기로 띄우고 모서리 반경, 여백, 글자 크기·굵기, 선 굵기, 선택 효과를 하나씩 비교합니다. DOM·CSS에서 읽을 수 있으면 실제 값을, 정지 이미지에서만 짐작할 수 있으면 추정치를 적습니다. 제3자 이미지는 저장소 밖 임시 위치에서만 엽니다.

## 1차: 구조와 콘텐츠

- 실제 콘텐츠로 만듭니다. 사용자가 준 카피가 없으면 주제에 맞는 자리 표시를 쓰되, 수치·고객사·후기는 지어내지 않습니다.
- 정보 순서, 섹션 구성, 반응형 구조, 상태(로딩·빈 화면·오류)를 잡습니다.
- 토큰은 CSS 변수로 먼저 선언하고 컴포넌트는 변수만 참조합니다. 컴포넌트 안에 hex를 직접 쓰지 않습니다.
- 이 단계에서 장식(그림자, 그라디언트, 애니메이션)을 넣지 않습니다. 선과 상자도 최소로: 묶음은 여백으로 먼저 만들고, 여백으로 안 될 때만 선을 더합니다.

## 2차: 타입 · 색 · 간격

AI가 만든 화면은 대부분 이 셋에서 티가 납니다. 간격이 전부 같고, 색 채도가 높고, 글자 위계가 평평합니다. 2차 직전에 `craft-floor.md`(바닥선)와 `visual-quality.md`(보기 좋음)를 읽습니다. 위계는 여백 → 굵기 → 크기 → 색 → 장식 순서로, 한 번에 한 요인씩 더합니다.

- **타입**: 스케일 단계가 눈에 보이게 차이 나는지. 제목은 크기·굵기로 강조하고 색이나 그라디언트로 강조하지 않습니다. 한글 본문은 `word-break: keep-all`을 검토합니다.
- **색**: 포인트 색 면적을 줄입니다. 회색 텍스트는 배경 색조를 섞어 씁니다. 순수 `#000`·`#fff`보다 토큰을 씁니다.
- **간격**: 관련 있는 것은 붙이고 무관한 것은 떼어 리듬을 만듭니다. 제목 위 간격 > 제목 아래 간격.
- **덜어내기**: 마지막에 테두리·그림자·배지·아이콘 중 하나를 뺄 수 있는지 봅니다. 빼서 나빠지지 않으면 뺍니다.
- **시그니처**: `DESIGN.md`의 시그니처 요소가 실제로 화면에서 눈에 띄는지 확인합니다. 과감함은 그 하나에만 씁니다.

## 조각 검토와 화면 조립

`verify.md`의 자동 거르기로 명백한 결함을 고칩니다. `webd-library`의 저장 명령으로 조각을 저장하고 편집기를 내부 브라우저에서 엽니다. 피드백을 반영하기 전에 `.draft.json`을 확인하고, 말로 받은 수정은 같은 ID에 저장해 편집기가 변경을 다시 읽게 합니다. 사용자가 그 버전을 확정할 때까지 같은 조각에서 작업합니다. 확정된 조각의 ID와 버전을 기록하고 다음 조각으로 넘어갑니다.

사용자가 확정한 조각으로 화면을 조립합니다. 연결된 상태, 포커스 순서, 화면 크기별 배치와 실제 작업 경로를 확인한 뒤 화면 단위로 사용자 검토를 받습니다. 조립 과정에서 확정된 조각의 모습이나 동작이 달라지면 달라진 부분도 다시 검토받습니다.

## 프로젝트의 UI 라이브러리

shadcn/ui, Radix 같은 라이브러리를 쓰는 프로젝트라면 구조와 접근성은 라이브러리에 맡기고, **토큰은 반드시 프로젝트 값으로 바꿉니다.** 기본 토큰 그대로면 그 자체가 AI 티입니다.

## CSS 주의

- 섹션 클래스와 요소 클래스의 우선순위가 서로 패딩·마진을 덮어쓰지 않게 합니다.
- 레이아웃을 흔드는 속성(width, height, top)은 애니메이션하지 않습니다.
- 이미지·임베드에는 크기나 `aspect-ratio`를 지정해 레이아웃 이동을 막습니다.
