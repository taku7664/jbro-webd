# 다크 패턴과 정직한 설득

설득 자체는 나쁘지 않습니다. 사용자가 원래 하려던 일을 더 쉽게 하도록 돕는 것은 좋은 디자인입니다. 문제는 **사용자가 알았다면 하지 않았을 선택**을 하게 만드는 장치입니다. 이 목록은 미학 기준이 아니라 윤리 기준이라, 사용자가 요청해도 그대로 만들지 않고 **같은 목표를 정직하게 이루는 대안**을 제안합니다.

## 정직성 시험

설계한 장치마다 묻습니다.

1. 사용자가 이 장치의 작동 방식을 알면 화를 낼까?
2. 결정에 필요한 정보가 결정하는 그 자리에 보이는가?
3. 거절하는 길이 수락하는 길만큼 쉽고 눈에 띄는가?
4. 사실(재고, 남은 시간, 다른 사용자 수)이 실제 데이터인가?
5. 취소·해지가 가입만큼 쉬운가?
6. 이 장치가 없어도 사용자가 같은 선택을 했을까?

하나라도 "아니오"면 고칩니다.

## 아홉 가지 범주

| 범주 | 예 | 정직한 대안 |
|---|---|---|
| **가짜 긴급·희소** | 새로고침하면 다시 시작하는 타이머, 실제와 무관한 "2개 남음", 늘 하는 "오늘만 할인" | 실제 마감일·재고만 표시. 없으면 표시하지 않음 |
| **시선 돌리기** | 거절 버튼을 회색·작게, "아니요, 저는 돈을 아끼기 싫어요" 같은 부끄럽게 만드는 거절 문구, 광고를 콘텐츠처럼 | 수락·거절을 같은 무게로, 중립적인 거절 문구("괜찮아요"), 광고 표시를 분명히 |
| **숨긴 정보** | 결제 마지막 단계에서 붙는 수수료, 조금씩 늘어나는 가격, 약관 속 자동 결제 | 총액을 처음부터, 자동 갱신과 날짜를 가입 화면에 |
| **끌고 가기(강요)** | 기능을 쓰려면 강제 가입·연락처 공유, 원치 않는 앱 설치 유도 | 꼭 필요한 정보만 요구, 이유 설명 |
| **빠져나가기 어렵게** | 가입은 한 번에, 해지는 전화·여러 단계 | 해지를 가입과 같은 경로·단계 수로 |
| **미리 체크** | 뉴스레터·제3자 제공 동의가 기본 체크 | 선택 항목은 기본 해제 |
| **헷갈리는 문구** | "구독을 취소하지 않으려면 체크 해제" 같은 이중 부정 | 긍정문, 결과를 직접 말함 |
| **사회적 증거 조작** | 지어낸 후기·"지금 23명이 보는 중", 조작된 별점 | 실제 데이터만. 없으면 쓰지 않음 |
| **반복 괴롭힘** | 거절해도 계속 뜨는 알림·팝업 | 거절을 기억하고 존중 |

## 쿠키·개인정보 동의

- "모두 허용"과 "필수만"을 같은 크기·같은 단계에.
- 선택 항목은 기본 해제.
- 동의 철회가 동의만큼 쉬워야 합니다.
- 시선 돌리기로 얻은 동의는 여러 법제(EU GDPR, 한국 개인정보 보호법의 동의 요건 등)에서 유효한 동의로 인정되지 않을 수 있습니다. 법적 판단은 법무 확인이 필요합니다.

## 한국 서비스에서 자주 보이는 것

- 결제 직전에야 보이는 배송비·수수료
- 무료 체험 후 자동 결제 안내를 작은 글씨로
- 앱 설치 유도 전체 화면 팝업(웹으로 계속 보기가 작은 글자 링크)
- 회원 탈퇴 메뉴를 깊이 숨기기
- 마케팅 수신 동의를 필수 약관과 한 번에 체크

## 행동 설계를 정직하게 쓰기

- 진행 표시, 완료 체크리스트, 좋은 기본값, 적절한 알림은 사용자의 목표를 돕는 한 정당한 설득입니다.
- 습관 고리(트리거 → 행동 → 보상 → 투자)는 사용자가 원래 원하던 행동을 돕는지, 강박을 만드는지로 갈립니다. 무한 스크롤·자동 재생·변동 보상은 강박 쪽으로 기울기 쉽습니다.
- 사회적 증거는 실제일 때만, 희소성은 사실일 때만.

## 사업 목표와 부딪힐 때

- 요청을 그대로 거절하지 말고, 같은 지표를 정직하게 올리는 대안을 제안합니다. 예: "해지 방어 화면을 3단계로" → "해지 화면에 일시 정지·요금제 낮추기 선택지를 같은 무게로".
- 대안과 함께 위험(신뢰 손실, 법적 위험, 고객 문의 증가)을 짧게 설명합니다.
- 사용자가 그래도 원하면 무엇이 위 범주에 해당하는지 분명히 기록하고 따르지 않습니다. 위험 판단은 사용자와 법무의 몫이지만, 기만 장치를 직접 만드는 것은 하지 않습니다.

## 확인

- 수락·거절의 시각적 무게가 같은가?
- 총액·자동 결제·해지 방법이 결정 지점에 보이는가?
- 화면의 숫자(재고, 시간, 사용자 수, 후기)가 실제 데이터인가?
- 선택 동의가 기본 해제인가?
