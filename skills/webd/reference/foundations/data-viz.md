# 데이터 시각화

차트는 **보는 사람의 질문**에 답하는 도구입니다. 데이터 형식이 아니라 그 질문이 차트를 정합니다. 장식된 차트는 답을 흐립니다.

## 질문 → 차트

| 보는 사람이 알고 싶은 것 | 차트 | 대신 쓰지 말 것 | 바꿀 때 |
|---|---|---|---|
| 범주 20개 이하 값 비교 | 세로 막대 | 원형 (각도는 정확히 못 읽음) | 범주 이름이 길면 가로 막대 |
| 순위 | 가로 막대, 내림차순 정렬 | 정렬 안 한 막대 | — |
| 시간에 따른 변화 | 선 | 막대 (각 기간이 따로인 것처럼 보임) | 분기처럼 끊긴 기간이면 막대 |
| 여러 계열의 시간 변화 | 여러 선 (5개 이하) | 누적 영역 (각 계열 값 읽기 어려움) | 5개 넘으면 작은 차트 여러 개 |
| 전체 중 부분 (2–4개, 크기가 크게 다름) | 원·도넛 | — | 정확한 값 비교가 중요하면 누적 막대 |
| 전체 중 부분 (5개 이상 또는 비슷한 크기) | 누적 막대, 트리맵 | 원형 | 위계가 있으면 트리맵 |
| 분포 | 히스토그램 | 막대 | 그룹 비교면 박스·바이올린 |
| 두 수치의 관계 | 산점도 | 선 (시간 순서처럼 보임) | 관계가 있을 때만 추세선 |
| 두 시점 사이 순위·값 변화 | 기울기 차트, 덤벨 | 선 | — |
| 기준·목표 대비 차이 | 발산 막대 | 일반 막대 | 순차 기여면 폭포 차트 |
| 흐름 | 생키 | 누적 막대 | — |
| 지역별 비율 | 단계 구분도 | 지도 위 원형 | 절대량이면 점 밀도 지도 |
| 카드 안의 맥락 (20점 이하) | 스파크라인 | 큰 차트 | 목표 비교면 불릿 차트 |
| 목표 대비 성과 KPI | 불릿 차트 | 속도계·원형 게이지 (공간 낭비, 각도 읽기) | — |

## 지각 정확도

사람이 크기를 정확하게 읽는 순서(정확한 것부터): **같은 기준선 위의 위치 → 다른 기준선 위의 위치 → 길이 → 각도·기울기 → 면적 → 부피 → 색의 진하기·채도**. 중요한 비교는 위쪽 수단으로 표현합니다. 원형·버블·3D가 약한 이유입니다.

## 정직한 인코딩

- **막대는 0에서 시작합니다.** 막대의 길이가 값이기 때문입니다. 선 차트는 0이 아니어도 되지만 축을 분명히 표시합니다.
- 3D 효과 금지. 원근이 크기를 왜곡합니다.
- 두 축 차트(왼쪽·오른쪽 다른 단위)는 상관관계를 꾸며 낼 수 있습니다. 가능하면 위아래 두 차트로.
- 면적으로 값을 표현할 때(버블) 반지름이 아니라 면적이 값에 비례해야 합니다.
- 비율 데이터를 절대량처럼, 누적을 기간값처럼 보이게 하지 않습니다.
- 일부 구간만 잘라 보여 줄 때는 잘랐다고 표시합니다.

## 잉크를 아낀다

- 데이터를 나르지 않는 잉크(굵은 격자, 배경 그라디언트, 그림자, 장식 아이콘)를 지웁니다. 격자는 아주 옅게 또는 없이.
- 범례 대신 **선 끝에 직접 라벨**. 눈이 범례와 차트를 오가지 않게.
- 축 라벨은 필요한 만큼만(0, 50, 100). 숫자 형식은 단위 포함, 천 단위 구분.
- 강조할 계열 하나만 색, 나머지는 회색. 모든 계열을 색으로 칠하면 아무것도 강조되지 않습니다.

## 색

- 범주: 서로 구별되는 색상 + 밝기도 다르게. 7개를 넘으면 구별이 무너집니다 → 묶거나 작은 차트 여러 개.
- 순차(양): 한 색상의 밝기 단계. 밝음 = 적음 또는 반대, 화면 전체에서 일관되게.
- 발산(기준 대비 위·아래): 양 끝 두 색상, 가운데 무채색.
- 빨강·초록만으로 좋고 나쁨을 나누지 않습니다. 모양·라벨·방향 화살표를 함께.
- 팔레트는 지각 균일한 공간(OKLCH)에서 만듭니다(`color.md`).

## 대시보드

- 대시보드는 **한눈에** 보는 화면입니다. 1순위 지표를 보려고 스크롤해야 하면 보고서입니다.
- 배치: 맨 위 핵심 지표 3–7개(맥락 스파크라인·목표 비교) → 그 지표들의 추세 → 세부 분해·표.
- 숫자 하나만 크게 두지 말고 **비교 기준**(지난 기간, 목표)을 같이. "1,240"은 의미가 없고 "1,240 (지난주보다 +8%)"은 의미가 있습니다.
- 같은 크기 지표 카드를 줄지어 놓는 "히어로 지표" 템플릿은 AI 기본값입니다. 중요도에 따라 크기를 다르게(`styles/instrument-panel.md`).
- 장식용 스파크라인·진행 링 금지. 데이터가 있을 때만.

## 접근성

- 차트에 제목과 한 문장 요약("3분기 매출이 2분기보다 12% 늘었다")을 글로 둡니다.
- 데이터 표를 함께 제공하거나 펼쳐 볼 수 있게.
- SVG 차트: `role="img"` + `aria-label` 또는 `<title>`, 상호작용 차트는 키보드로 점 이동.
- 차트 라벨이 가장 좁은 화면에서 11px 이상인지 계산합니다(SVG는 viewBox와 함께 줄어듦, `typography.md`).
- 툴팁에만 있는 정보는 키보드·터치에서 닿게.

## 확인

- 이 차트가 답하는 질문을 한 문장으로 말할 수 있는가?
- 막대가 0에서 시작하는가? 3D·이중 축 왜곡이 없는가?
- 흑백·색각 이상에서도 계열이 구별되는가?
- 범례 없이 직접 라벨로 읽히는가?
- 가장 좁은 화면에서 라벨이 읽히는가?
